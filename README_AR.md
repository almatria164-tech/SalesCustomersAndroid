# نظام المبيعات والزبائن — Android

تم تغليف صفحة HTML المرفقة داخل تطبيق Android أصلي باستخدام WebView.

المميزات الحالية:
- يعمل بدون إنترنت.
- يحفظ البيانات محلياً باستخدام localStorage.
- واجهة عربية RTL.
- الزبائن، المبيعات، سندات القبض، المشتريات، وكشف الحساب.

## البناء
افتح المجلد في Android Studio، ثم Build > Build APK(s).

الحد الأدنى Android 6.0 (API 23).
